  • 如果两个质数差距很小（即 q - p 很小），那么：

    推导过程如下：

    • 令：a = (p + q) / 2，b = (q - p) / 2
    • 则：n = a^2 - b^2
    • 所以我们可以从 a = ⌈√n⌉ 开始，不断尝试 b^2 = a^2 - n 是否是完全平方数
    • 如果找到了某个 a 使得 b^2 = a^2 - n 是完全平方数，就能还原 p = a - b, q = a + b
